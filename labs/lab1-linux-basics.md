# Lab 1: Linux Basics

## Objective
Learn navigation, file operations, system monitoring, and basic troubleshooting.

## Commands Used
```bash
mkdir test
cd test
touch file.txt
ls -l
pwd
```

## Workflow: Creating a directory, adding a file, and verifying it

### Commands:
--------------------------------------------------------------------
mkdir test1
cd test1
touch file.txt
ls -1
pwd
--------------------------------------------------------------------

### Output:
--------------------------------------------------------------------
file.txt
/mnt/c/Users/Hp/sre-labs/linux-and-networking-fundamentals/test1
--------------------------------------------------------------------

### Learning:
- `mkdir test1` creates a new directory named **test1**.
- `cd test1` moves you inside that directory.
- `touch file.txt` creates an empty file named **file.txt**.
- `ls -1` lists files one per line, making output clean and easy to read.
- `pwd` shows the full path of your current directory, confirming you are inside `/test1`.
- This workflow represents essential Linux filesystem actions every SRE must know (create, navigate, verify).
